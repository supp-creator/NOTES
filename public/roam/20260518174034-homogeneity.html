In First-Order ODEs (Function Scaling)

A firt-order ODE in the form: \(\frac{dy}{dx} = f(x,y)\) is considered homogeneous if the function f(x,y) depends on the ration \(\frac{y}{x}\) .

To test for homogeneity:

\[f(tx, ty) = t^{n} f(x,y)\]

A function is homogeneous of degree n if both variables are able to be scaled by constant t and yields the original function multiplied by tn.

If the function is rewritten in:

\[M(x,y)dx + N(x,y)dy = 0\]

The function is homogeneous if the degree of M(x,y) and N(x,y) are equal.

For example:

\[(x^{2} + y^{2})dx + xydy = 0\]

This function is homogeneous.

Individually, x2 and y2 both have degree of 2.

xy also has degree of 2. As x1 × y1 = xy.

EVERY TERM IS DEGREE 2.

If the degrees are mixed, that is not homogeneous.

You must also inspect the variables. If the variables x and y always appear to be grouped together as a fraction, the function is homogeneous.

Examples:

\[ \frac{x}{y} || \frac{y}{x}\]

\[sin(\frac{x}{y}), cos(\frac{y}{x}), tan(\frac{y}{x})\]

\[ln(y) - ln(x) = ln(\frac{y}{x})\]

\[e^\frac{x}{y}\]

Homogeneous first-order equations cannot have standalone numbers added or subtracted. This is becuase constants break the scaling property.

\(\frac{dy}{dx} = \frac{x + y}{x}\) is homogeneous.

\(\frac{dy}{dx} = \frac{x + y + 1}{x}\) is not homogeneous.

Solving First-Order ODEs

The idea to solve any first-order ODE is to simplify it by substituting the ratio of x and y.

\[ v = \frac{y}{x}\] → \[y = vx\]

Remember that:

\[y' = v * 1 + x * \frac{dv}{dx}\] → \[ \frac{dy}{dx} = v + x \frac{dv}{dx}\]

Substitute these values into the original equation.

Then to apply separation of variables. Before converting v back to the ratio.

Homogeneity in Linear ODEs (Structure and Form)

A linear ODE is homogeneous if every term contains the dependent variable or one of its derivatives AND if the equation is set to 0.

It can generally be written as:

\[a_{n}(x)y^{n} + a_{n-1}(x)y^{n-1}+..._a_{1}(x)y' + a_{0}(x)y = 0\]

There can be no forcing term.

If y = 0 is a valid solution, it is homogeneous.

If y1 and y2 are solutions to a linear homogeneous ODE, then any linear combination of C1y1 + C2y2 is also a solution.

To solve

If the coefficients are constant, use a characteristic polynomial.
