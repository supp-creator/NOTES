#+title: Linear ODEs

Linear Ordinary Differential Equations can be written in this standard form:

$$\frac{dy}{dx} + P(x)y = Q(x)$$


* Solving linear differential equations

1. Find the integrating factor /\mu(x)/

   $$\mu(x) = e^{\int P(x) dx}$$

   Adding the constant of integration of /C/ is unneccesary.

2. Multiply each term by the integratin factor

   $$\mu(x) * \frac{dy}{dx} + \mu(x) * P(x)y = Q(x) * \mu(x)$$

3. Use the product rule to simplify

   $$\frac{d(\mu(x)*y)}{dx} = \mu(x) * \frac{dy}{dx} + (\mu(x) * P(x)) * y$$

   $$\frac{d(\mu(x) * y)}{dx} = Q(x)*\mu(x)$$

4. Integrate both sides with respect to /x/.

   $$\mu(x) * y = \int Q(x) * \mu(x) dx$$

5. Isolate /y/ by dividing both sides with the integrating factor. This is the general solution.

   $$y = \frac{1}{\mu(x)} * [ \int Q(x) * \mu(x) dx]$$
